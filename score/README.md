問題文
====
とあるスポーツで、チームAとチームBが試合を行いました。得点をとったことを記録している人がいましたが、
得点を記録する機械が試合が終了した瞬間に故障してしまいました。得点をとったことの記録Tᵢ（Aの時はチームAが、Bの時はチームBが得点したことを表す）とその回数Nが与えられます。勝利したチームはどちらか判定してください。

制約
----
- $1 \leq N \leq 10$
- TᵢはAまたはB

入力
----
```
N　
T₁...Tₙ
```

出力
-----
チームAが勝利した時はAを、チームBが勝利した時はBを、引き分けの際はdrawを出力してください


サンプル
=====
```入力1
5
A A B B A
```

```出力1
A
```

```入力2
6
B B B B A A
```

```出力2
B
```

```入力3
4
B B A A
```

```出力3
draw
```
