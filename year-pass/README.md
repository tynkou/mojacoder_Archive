問題文
=====
とある遊園地では購入した日から一年間有効で無料で入園できる年間パスポートが売られています。Aさんはこの遊園地に一年間でN回行く予定です。
入場チケットの値段Xと年間パスポートの値段Yが与えられます。年間パスポートを購入する方がお得か判定してください。なお、入場チケットは１回限りの入場が可能で
年間パスポートは有効期限の間は何回でも無料で入場できるものとし、買ったその日から有効になるものとします。

制約
-----
- $1 \leq N \leq 365$
- $1000 \leq X \leq 5000$
- $5000 \leq Y \leq 20000$

入力
-----
入力はすべて整数である。
```
N
X Y
```

出力
-----
年間パスポートを買うのにかかる金額が入場チケットをN回買うときの金額以下のとき Yes、 そうでないとき No と出力してください。


サンプル
=====
```入力1
6
3000 10000
```

```出力2
Yes
```

```入力2
4
2500 10000
```

```出力2
Yes
```
