問題文
=====
とある中学校でテストが行われました。
N人の生徒がいて、I番目の生徒の得点はMᵢ点です。
テストの平均点を求め、L番目の生徒の得点が平均点以上か判定してください。

制約
-----
- $1 \le I \le N \leq 5$
- $0 \le Mᵢ \le 100$
- $1 \le L \le N$

入力
-----
入力はすべて整数である。
```
N
M₁...Mₙ
L
```

出力
-----
L番目の生徒の得点が平均点以上のとき Yes、そうでないとき No と出力せよ。


サンプル
=====
```入力1
5
55 67 98 46 78
3
```

```出力2
Yes
```

```入力2
5
33 89 78 90 76
1
```

```出力2
No
```
