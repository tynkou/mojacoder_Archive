問題文
=====
Aさんは計算ドリルを解いています。$N$問の足し算のページで、全ての問題を解き終わりました。二つの整数$Aᵢ$,$Bᵢ$と、Aさんが出した答え$Kᵢ$が
与えられます。各問題$ Aᵢ+Bᵢ $の正誤を判定してください。

制約
-----
- $1 \leq I \leq N \leq 10$
- $1 \leq A,B \leq 9$
- $2 \leq K \leq 18$

入力
-----
入力はすべて整数である。
```
N
A₁ B₁ K₁
...
Aₙ Bₙ Kₙ
```

出力
-----
正解ならYes、不正解ならNoを出力してください。

サンプル
=====
```入力1
5
1 2 3
1 4 6
3 4 8
5 6 11
4 5 9
```

```出力2
Yes
No
No
Yes
Yes
```

```入力2
3
1 1 2
3 4 10
2 9 11
```

```出力2
Yes
No
Yes
```
