問題文
=====
Aさんは学校で九九を習いました。Aさんは２つの数の掛け算の中で、どちらの数も９以下のものは計算できますが、１０以上の数が一つでもあるものはまだ計算できません。２つの整数$N,M$が与えられます。
$N × M$が計算できるか判定し、計算できるならその答えを出力してください。

制約
-----
- $0 \leq N \leq 15$
- $0 \leq M \leq 15$

入力
-----
入力はすべて整数である。
```
N M
```


出力
-----
$N × M$が計算できるならその答えを、計算できないならNoを出力してください。


サンプル
=====
```入力1
2 5
```

```出力1
10
```

```入力2
10 5
```

```出力2
No
```
