問題文
====
Aさんはとある検定を受けました。その検定には分野Aと分野Bそれぞれの試験があり、両方で共通である合格点K以上の得点を取らないと検定に合格できません。
Aさんの分野Aの試験の得点Nと分野Bの得点Mがあたえられます。Aさんがこの検定に合格したか判定してください。

制約
----
- $0 \leq N,M \leq 100$
- $0 \leq K \leq 100$

入力
----
入力はすべて整数である。
```
N M K
```

出力
-----
Aさんがこの検定に合格したならYes、そうでないとき No と出力してください。

サンプル
=====
```入力1
91 89 70
```

```出力2
Yes
```

```入力2
67 72 75
```

```出力2
No
```
