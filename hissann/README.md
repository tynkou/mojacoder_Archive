問題文
====
Aさんは二桁の整数の掛け算$A ×B$の筆算をしています。
$A$×($B$の一の位）、$A$×($B$の十の位）、$A ×　B$を出力してください。
（参考）https://ja.wikipedia.org/wiki/筆算#筆算による乗算

制約
-----
- $10 \leq A,B \leq 99$

入力
-----
入力はすべて整数である。
```
A,B
```

出力
-----
$A$×($B$の一の位）、$A$×($B$の十の位）、$A ×B$を一行で出力してください。


サンプル
=====
```入力1
23 45
```

```出力1
115 92 1035
```

```入力2
14 98
```

```出力2
112 126 1372
```
