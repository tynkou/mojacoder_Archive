問題文
=====
Aさんはサイトにログインしようとしています。入力したパスワードNと設定しているパスワードMが与えられます。
入力したパスワードが正しいか判定してください。

制約
-----
-　N,Mは6文字以上10文字以下の英数字

-　N,Mの文字数は等しいとは限らない

入力
-----
```
N
M
```

出力
-----
入力したパスワードが正しいならYes,まちがっているならNoを出力してください


サンプル
=====
```入力1
password1
password1
```

```出力2
Yes
```

```入力2
password1
password2
```

```出力2
No
```
